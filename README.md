# Z-1080™

**Z-1080™** — це модульний експериментальний безпековий фреймворк для Windows та Linux, який включає інструменти:

- генерацію паролів;
- експериментальні криптографічні модулі;
- майбутній GUI-інтерфейс;
- інтеграцію з PenTest-лабораторією.

Проєкт створюється як навчально-лабораторний інструмент для дослідження безпеки, криптографії, генерації ключів та автоматизації тестування.

---

## 🧩 Функціональні модулі

| Статус | Компонент           | Опис |
|--------|---------------------|------|
| ✔️     | Core Generator      | CLI-генератор паролів з опціями: довжина, алфавіт, обмеження |
| 🧪     | Restricted Mode     | Генератор з кастомним / обмеженим алфавітом |
| ❌     | Export to Secure File | Збереження результатів у `.txt` або зашифрований `.enc` файл |
| 🔄     | GUI                  | Майбутній графічний інтерфейс (Tkinter / PySide) |
| 🧭     | Future Integration   | Використання в PenTest-сценаріях, інтеграція з іншими інструментами |

---

## 🚀 Запуск

### Windows

```powershell
python z1080.py -l 16 -g
```

### Linux / Ubuntu

```bash
python3 z1080.py --length 20 --strong
```

(Назви аргументів можуть відрізнятись залежно від фактичної реалізації.)

---

## 🧪 Приклади

```bash
z1080.exe --length 32 --save
```
